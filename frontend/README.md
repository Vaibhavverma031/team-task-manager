# Team Task Manager

A Full Stack Team Task Manager application built using React, Node.js, Express.js and MongoDB.

## Features

- User Authentication (Signup/Login)
- Role Based Access Control (Admin/Member)
- Project Management
- Task Assignment
- Task Status Tracking
- Dashboard Analytics
- Overdue Task Detection

## Tech Stack

### Frontend
- React.js
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Authentication
- JWT
